# mesa games store
A GOG-inspired digital game store built as a learning project only. The application focuses on practicing full-stack web development concepts, including game catalog management, user authentication, purchasing, and order management.

Built with: Laravel, React, Inertia.js, SQLlite, and shadcn as UI Componen.
